# myorch

myorch owns this file and may refresh it during `myorch init`.

For personal project rules, create `.claude/myorch.local.md` or add rules elsewhere; do not edit this file directly if you want changes to survive future init runs.

## Build / Test
- Run `npm run verify:all` before trusting changes to myorch itself.
- Project work advances only when the current verifier command returns PASS.

## Workflow
- Use `/goal <task>` to create or refresh `spec.md` and `plan.md`.
- Use `/status` to inspect ratchet progress.
- Use `/switch claude` or `/switch codex` only when manually overriding routing.

## Critical Rules
- Do not directly edit `plan.md` checkboxes.
- Verifier evidence, not prose, advances the ratchet.
- Metareview must cite actual verifier output.
- Compact is not triggered by hooks; compact hooks only back up and restore context.
